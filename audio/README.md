# 小亮音频文件说明

## 音频文件列表

为了实现"听小亮唱歌"功能，需要在 `audio/` 目录下准备以下音频文件：

### 鹦鹉叫声类（玄凤鹦鹉特有的声音）
1. **cockatiel-chirp-1.mp3** - 玄凤鹦鹉的啾啾叫声（短促清脆）
2. **cockatiel-whistle-1.mp3** - 玄凤鹦鹉的口哨声（悠长悦耳）
3. **cockatiel-sing-1.mp3** - 玄凤鹦鹉的歌唱声（组合音调）

### 训练旋律类（用于训练鹦鹉学唱歌）
4. **melody-do-re-mi.mp3** - 简单的 do re mi 旋律（音阶训练）

## 音频要求

- **格式**：MP3
- **时长**：3-10秒（不要太长，避免重复播放时让人烦）
- **音质**：清晰，无明显杂音
- **音量**：适中，播放时自动设置为 70% 音量

## 音频来源建议

### 免费资源
1. **Freesound.org** - 搜索 "cockatiel", "bird chirp", "bird whistle"
2. **Zapsplat.com** - 动物声音库
3. **YouTube Audio Library** - 免费音乐和音效

### 自己录制
1. 使用手机或录音设备录制自家鹦鹉的声音
2. 使用录音软件（Audacity）剪辑和优化音频
3. 确保音频质量清晰

### 在线生成
1. 使用在线旋律生成器生成简单的 do-re-mi 旋律
2. 使用音乐合成软件创作鹦鹉叫声

## 如何添加音频文件

1. 准备好 MP3 文件
2. 将文件重命名为上述列表中的文件名
3. 将文件放到 `audio/` 目录下
4. 刷新网页，点击"听小亮唱歌"按钮测试

## 功能说明

- 点击"听小亮唱歌"按钮时，会：
  - 随机显示一段提示文字
  - 随机播放一个音频文件
  - 音频播放时会自动停止之前的音频
  - 播放音量自动设置为 70%

## 注意事项

- 浏览器需要用户交互才能播放音频（这是浏览器的安全策略）
- 如果音频文件不存在，控制台会显示错误，但不会影响页面功能
- 建议每个音频文件不要超过 200KB，避免加载缓慢

## 扩展建议

未来可以添加更多音频文件：
- cockatiel-chirp-2.mp3
- cockatiel-whistle-2.mp3
- melody-twinkle-star.mp3（小星星）
- melody-happy-birthday.mp3（生日快乐）
- 等等...

只需将新文件添加到 `audio/` 目录，并在 `singAudioFiles` 数组中添加文件名即可。
